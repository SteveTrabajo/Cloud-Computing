# Cloud Computing

Coursework for the Cloud Computing course (Semester 6, Braude).
Mostly Jupyter notebooks plus the homework write-ups and their source papers.

## Layout

| Folder | What's inside |
|--------|---------------|
| `Exercises/` | In-class exercise notebooks (`ex1`..`ex7`) |
| `HW1/` | Homework 1, Chameleon (PDF) |
| `HW2/` | Homework 2, Chameleon notebook plus reference papers |
| `HW3/` | Homework 3, Chameleaf plant-monitoring app (notebook) plus reference papers |

## Running

The notebooks are built for Google Colab, so the easy path is to open the
`.ipynb` in Colab and run top to bottom. Locally:

```bash
pip install jupyter
jupyter notebook
```

## Notes

HW2 and HW3 center on *Monstera deliciosa* (Swiss cheese plant) monitoring.
The PDFs in those folders are the papers the work builds on.
